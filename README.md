# Feit Planner — расширенная веб-версия

## Запуск
Откройте `index.html` в браузере. Для PWA и offline-кеширования нужен HTTPS или локальный сервер (`python -m http.server 8000`).

## GitHub Pages
Загрузите содержимое папки в корень репозитория. В Settings → Pages выберите Deploy from a branch → main → /(root). После публикации откройте `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

## Данные
Данные хранятся в IndexedDB устройства/браузера, в базе `ritm`. Старая версия приложения использовала ту же базу. Автоматическая миграция доступна **только при совпадении origin** (домен + протокол + порт). При переходе между адресами воспользуйтесь экспортом и импортом JSON. При очистке данных сайта данные могут быть потеряны.

## Реализовано
Новый адаптивный интерфейс, разделы «Сегодня», «Календарь» (недельный выбор даты), «Задачи», «Цели», «Проекты», «Настройки», создание задач и событий, локальное сохранение, проверка дедлайнов, расчёт свободных интервалов, предварительный просмотр перестроения, фокус-таймер, импорт/экспорт JSON, PWA-сборка.

## Ограничения
Это рабочая расширенная версия, **не полный аналог TickTick**. Нет сервера и облачной синхронизации, push-уведомлений вне открытого приложения, полноценного drag-and-drop, месячного календаря, пользовательских подзадач и автоматического создания повторов. Поля повторения сохраняются, но не запускают генерацию новых задач. При закрытии фокус-модального окна без завершения сессия не записывается. Ручной импорт JSON требует подтверждения. Не используйте это приложение как единственное место хранения важных задач без резервных копий.
