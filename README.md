# Feit Planner 2.0 — обновление для GitHub Pages

1. **Сначала скачайте JSON-копию из старого приложения.**
2. Загрузите файлы из этого архива в корень того же репозитория `Marklanskoy/Feit-Plainer-`, заменив совпадающие. Не загружайте сам ZIP и не создавайте внешнюю папку.
3. Сохраните прежнюю настройку Pages: `main` → `/ (root)`. `index.html` должен быть в корне.
4. После публикации закройте старые вкладки приложения и снова откройте прежний адрес в Safari. Если база ждёт обновления, закройте оставшиеся старые вкладки. **Не очищайте данные сайта.**
5. При следующем запуске предусмотрен перенос прежней базы `ritm`. Перед переносом записывается локальная страховочная копия, но она не заменяет отдельно скачанный JSON.

Приложение не откроется как обычная программа через предпросмотр HTML в «Файлах». Запускайте опубликованный сайт. Добавление на экран iPhone: Safari → «Поделиться» → «На экран Домой».

## Файлы

`index.html`, `sw.js`, `manifest.webmanifest`, `icon.svg`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png`. Файл `.nojekyll` служебный. Сборка не нужна: JavaScript и CSS уже включены в HTML.

Данные локальные. Облачной синхронизации и фоновых push-напоминаний нет. Старые неработавшие настройки повторения сохранены как подсказки; активируйте нужные повторения в карточках.

49 тестов логики/контракта хранилища и 11 интерфейсных проверок пройдены. Часть тестов использует модель хранилища. Реальные IndexedDB/PWA и Safari на iPhone ещё требуют проверки после публикации. Подробный протокол и исходники предоставлены отдельным архивом. Это не утверждение о полной коммерческой готовности.
